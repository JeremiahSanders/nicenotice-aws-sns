# TopicResolvers.Mapped method

Creates a new [`ISnsTopicResolver`](../ISnsTopicResolver.md) that uses a mapping of event stream identifiers to SNS topic ARNs. A default topic can be specified, which will be used if no mapping is found for a given event stream. If no mapping is found and no default topic is specified, an [`SnsStreamRoutingException`](../SnsStreamRoutingException.md) exception will be thrown.

```csharp
public static ISnsTopicResolver Mapped(IEnumerable<KeyValuePair<EventStreamId, string>> map, 
    string? defaultTopic)
```

| parameter | description |
| --- | --- |
| map | A map of event streams to SNS topic ARNs. |
| defaultTopic | A default SNS topic ARN, which will be used if no mapping is found for a given event stream. |

## Return Value

Returns a new [`ISnsTopicResolver`](../ISnsTopicResolver.md) instance.
